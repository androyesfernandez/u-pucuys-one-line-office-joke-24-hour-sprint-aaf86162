One single-line joke about office life, written by `main.ts` to
`/output/entry.txt`. The line is a fixed, duel-tested joke: one
concrete office scene, setup and punchline on a single line, 200
characters at most — the kind you send a colleague after a meeting
that should have been an email.

Run it with `node main.ts`. It needs nothing but Node and writes
only `/output/entry.txt`.
